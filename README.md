## 📖 About

This repository contains coursework completed as part of **Projektowanie Systemów Informatycznych (Information Systems Engineering)** at the **University of Warsaw**.

The course introduced practical data science and text mining techniques using **R**, with a particular focus on processing, analyzing, and extracting information from textual data.

The repository contains exercises and reports covering the complete workflow from basic data processing to sentiment analysis, text clustering, topic modeling, word associations, and TF-IDF.

\---

## 🎯 Topics Covered

The coursework includes:

* Data Science workflow
* Text frequency analysis
* Sentiment analysis
* Sentiment analysis over time

* Vector space representation of text
* K-Means clustering

## 🔍 Selected Topics

### 📊 Data Science Workflow

Introduction to the data science workflow in R, including data import, preparation, exploration, transformation, and visualization.

### 📝 Text Frequency Analysis

Processing textual data and examining word frequencies to identify the most commonly occurring terms and patterns.

### 😊 Sentiment Analysis

Application of sentiment dictionaries to classify words and analyze emotional characteristics of textual data.

The coursework also explores changes in sentiment over time using real-world textual datasets.

### 🧮 Vector Space Representation

Representation of textual documents as numerical vectors, enabling mathematical comparison and further machine learning analysis.

### 🔵 K-Means \& Text Clustering

Application of **K-Means clustering** to group documents based on similarities in their textual representations.

### 🧠 Topic Modeling with LDA

Use of **Latent Dirichlet Allocation (LDA)** to identify latent topics within collections of documents.

### 🔗 Word Association Analysis

Exploration of relationships and co-occurrence patterns between words in textual datasets.

### 🔎 TF-IDF

Application of **Term Frequency–Inverse Document Frequency (TF-IDF)** to measure the importance of words within documents and document collections.

## 🚀 Final Course Project

The techniques explored throughout the course were later applied in a separate final project:

### 🤖 ChatGPT vs Gemini Reviews Analysis

A comparative analysis of approximately **40,000 user reviews** of ChatGPT and Gemini, combining:

* sentiment analysis using the NRC emotion lexicon,
* text mining and tokenization,
* word frequency analysis,
* word association analysis,
* data visualization,
* reproducible reporting with R Markdown.

The complete project, including source code, datasets, documentation, and the generated analytical report, is available in a separate repository:

[**ChatGPT vs Gemini Reviews Analysis**](https://github.com/vanitskiy18/chatgpt-vs-gemini-reviews-analysis)
